# 索引要有"从哪读起"，否则等于没有索引

## 出处
- 文档集的常见失败：**按主题组织对作者友好，对读者是迷宫**。
  Diátaxis 的核心主张之一就是按"读者此刻在做什么"组织入口，而不是按知识分类：
  <https://diataxis.fr/>

## 现场
`docs/kb/` 112 篇、9 个板块。按主题分组对我（作者）很好用，但新人打开只看到 100 多个标题，
**不知道该从哪篇开始**。

## 做法
索引顶部加 3 篇"第一次读"路径（规则对齐 → 门禁可信度 → 错误分类），并让检查守着：

```js
const pathLinks = [...pathBlock.matchAll(/\]\(([^)]+\.md)\)/g)].map((m) => m[1])
if (pathLinks.length < 3) console.log('FAIL …缺「第一次读」的阅读路径')
else if (pathMissing.length > 0) console.log('FAIL 阅读路径里这些文件不存在')
```

## 写的时候踩到两个真问题
1. 检查用了不存在的变量 `ok` → 路径一坏就 **抛异常**（比不检查更糟）；
2. 检查块被插进别的 `if/else` 里，**只有"篇数一致"时才执行** —— 等于半个死检查。

这两条都印证了 [门禁也会装死](gate-mutation-check.md)：**新加的检查必须注入一次错误，确认它真的会红。**

## 是否已落地
✅ 0.9.85。验证：删掉一篇链接 → FAIL 且 exit=1；还原 → exit=0。

## 还没做的
- 路径只覆盖"完全新人"；没有面向"想改代码的人"和"想排查故障的人"的路径；
- 路径顺序没有强制（改顺序不会报错，只有数量与存在性）。
