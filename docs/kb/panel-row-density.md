# 面板行也不能"一堵墙"：六段拼一行，拆成三行

## 出处
- 与 [弹层是摘要屏](popover-is-a-summary-screen.md)、[时间线行两行封顶](timeline-rows-two-lines.md) 同族：
  同一个毛病会在不同载体上重复出现。

## 现场
浅色主题出图时，总览第一条的说明行：

```
README 收尾与发布 · s1 · 每 60s · 轮询 15 秒前 · 唤醒 5 分钟前 · 上次唤醒失败 #9 · 50 小时前 · 目标: 把 0.8.x 的文档补齐
```

六段用 ` · ` 串成一行，1000px 下折两行，读起来是一堵墙。
**这正是弹层当初被吐槽的同一个毛病 —— 修了弹层，它在面板里原样还在。**

## 改法（三行，各管一件事）
```
README 收尾与发布 · s1 · 每 60s                        ← 是谁
轮询 15 秒前 · 唤醒 5 分钟前 · 上次唤醒失败 #9 · 50 小时前   ← 节律与最近结果
目标: 把 0.8.x 的文档补齐                                ← 目标（有才显示）
```

## 判据
**一行只回答一个问题。**

- "是谁"（标题/会话）—— 一行
- "节律与最近结果"（每 60s / 轮询 / 唤醒 / 上次）—— 一行
- "目标" —— 一行

超过三行就说明某一行塞了两件事，该再拆；只有一行但塞了六段，就是这次的形态。

## 教训
**修一类问题时，全局搜一遍同样的写法。**
弹层里的 5 行说明拆掉了，面板里的 6 段拼串却留着 —— 因为当时只看了弹层的截图。
出图要覆盖**所有承载同类信息的界面**。
