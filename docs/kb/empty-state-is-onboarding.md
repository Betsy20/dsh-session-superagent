# 空态是引导页，不是空表格

## 出处
- 与 [弹层是摘要屏](popover-is-a-summary-screen.md)、[错误态要带动作](error-state-needs-an-action.md) 同族：
  都是在讲"界面处于非正常状态时该说什么"。
- NN/g《Empty States in Complex Applications》（本轮未复核原文）：
  <https://www.nngroup.com/articles/empty-state-interface-design/>

## 现场（空态出图）
```
• ① 填一个仓库（owner/name，比如 MYCF711/dsh-session-superagent）
• ② 选间隔（默认 60 秒；建议先设 300 秒，别把 API 打满）
• ③ 点「添加到当前会话」——之后仓库有动静，这个会话就会被叫醒
```

三个问题叠在一起：
1. **列表符号 `•` 和步骤号 `①` 重复**，一行开头两个记号；
2. 步骤标题和说明挤在同一行，600px 下折成三段，分不清哪段是哪段；
3. `①` 是字符，读屏器念"带圈数字一"而不是"第 1 步"。

## 改法：圆形步骤号 + 标题 + 说明
```
(1) 填一个仓库
    owner/name，例如 MYCF711/dsh-session-superagent
(2) 选间隔
    默认 60 秒；先设 300 秒，别把 API 打满
(3) 点「添加到当前会话」
    之后仓库有动静，这个会话就会被叫醒
```

- `<ol>` + `list-style: none`（去掉重复符号）+ `aria-hidden` 的圆形步骤号；
- 标题 13px/500，说明 12px/tertiary —— 两行就能分出主次；
- 底部保留一个主按钮 + 一句"想先看看效果？先勾仅观察"。

## 判据
**空态要回答三个问题：现在是什么状态 / 下一步做什么 / 我自己会不会搞坏。**
三样缺一，客户就会去翻 README（或者干脆关掉面板）。

另外：**别用装饰性字符表达结构。** `①` 在视觉上像步骤号，在无障碍树里却只是一段文字；
真要表达"第几步"，用 `<ol>` + 样式把序号画出来。

## 是否已落地
✅ 0.9.152。空态用例改为**断言结构**（3 个 `dt-step`、步骤号连号 1/2/3），不再断言字符 `①`。

## 还没做的
- 「仅观察」那条脚注在 600px 下会折两行，还没量是否值得收进 `title`；
- 判定页空态只有一行「还没有主理鱼。」，可以像总览那样给三步。
