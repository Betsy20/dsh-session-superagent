# 窄屏不是"缩小的宽屏"：单列布局要重排节奏

## 出处
- 与 [页面子块之间要有节奏](screens-need-vertical-rhythm.md) 同族：宽屏靠列对齐，窄屏只能靠**分组的间距**。
- 容器查询（`@container`）让"按面板宽度"而不是"按窗口宽度"生效：
  <https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries>

## 现场（600px 出图）
| 页 | 表现 | 结论 |
|---|---|---|
| 总览 | 页头、指标条、行内容都能折行 | 可以 |
| 触发 | 输入框随容器收缩，两个时间选择器仍在一行 | 可以 |
| **设置** | 导航变横向 chip（好），**`dt-kv` 单列后 label 与 value 贴在一起**，五行连读像一段话 | 要改 |

具体来说：`仓库 / MYCF711/… / gh CLI / 可用 · gh version / 凭证 / 使用面板配置的 token`
—— 中间只有 2px gap，读起来是连续五行，分不清哪行是标签、哪行是值。

## 改法
在容器查询里给单列 `dt-kv` 的 label 加 `margin-top: 4px`（第一个除外），`gap` 2px → 6px。
每组「标签 / 值」读成一个块。

## 判据
**宽屏靠"列"分块，窄屏只能靠"间距"分块。**
同一份数据在宽屏有 `max-content 1fr` 两列，天然分组；塌成单列后，
如果不同组之间和组内一样的间距，信息就糊在一起了。

## 顺带两个工装/习惯
- 预览新增 `--mobile`（预览框压到 600px），窄屏从此可出图；
- 往巨型 CSS 字符串里插规则时，`\n` 必须写**转义**。这次我写成真换行，`node --check` 立刻报
  `Invalid or unexpected token`—— **改完立刻 `node --check client.js`**，别等测试。

## 后续（0.9.143）：弹层在窄窗口会溢出
弹层宽度写死 368px，`left` 会夹在窗口内，但**宽度本身没夹** —— 360px 窗口下右侧整块被切掉（出图确认）。

两道改法：
1. **JS**：`width = Math.min(368, max(240, innerWidth - 16))`；
2. **CSS 兜底**：`.sa-dock-panel { max-width: calc(100vw - 16px); box-sizing: border-box }`。

> 经验：**"内容不溢出"要同时管住"容器宽度"和"内容宽度"。**
> 只夹 `left` 是典型的漏一半 —— 位置对了，尺寸还会顶出去。
