**旧文件**：`"enabled": "false"`。这是 CHANGELOG:1754 明确记过的真机现场（*「字符串 `"false"` 让守照常轮询」*）。

**代码**：

- `lib/index.js:1734` — `enabled: isEnabled(w),` → `isEnabled`（`lib/index.js:201`）认 `"false"` / `"0"` / `"no"` / `"off"` → **false**
- `lib/watch.js:1120` — `enabled: w.enabled !== false,` → 只认布尔 `false` → **true**

**真实输出**（用例 5，同一次运行、同一份数据，两处实现并排）：
