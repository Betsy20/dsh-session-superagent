「客户升级时覆盖文件会破坏什么」，分三种情况（**建议照抄进 README**）：
- **pnpm 自己升级**（`add @latest`）：unlink 旧 inode + 建新硬链接，**安全**，store 和别的项目都不受影向；

- **`rm -rf node_modules`**：硬链接是独立目录项，store 不受影响（这点是安全的，值得写一句让客户别怕）。

- 安装时 `reconcile()` 会 `for (const file of bundlePatchPaths(...)) loadOverlayPatches("dsh", file)` ——

- 自洽性：profile 自己的 `cordis.patch.yml` 里 `session-superagent` 出现 **0 次**（`grep -c` 实测），
