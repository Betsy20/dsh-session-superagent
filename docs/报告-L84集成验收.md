# L84a 集成验收：确认弹层与 DecisionLine

## 实现

- `ConfirmButton`：触发按钮只打开 Modal；取消/Escape/背板不执行；确认期间 `busyRef + busy` 双锁防重复；成功才关闭。
- 主面板与卫星环共用同一组件；不再叠加原生确认框。
- `Modal` 增加 `description / footer / className`，`onClose` 放 ref，轮询重渲染不重置焦点 effect；保留 Escape、Tab 陷阱与焦点归还。
- 判定日志按日期分组，每组独立 `Section + ul.dt-list`；每条为 `li.dt-row.dt-link.dt-ticket`，含状态、仓库、编号、原因与 `<time datetime>`。
- Trace 与运行时事件仍为 `ol.dt-timeline`，不与 DecisionLine 混用。

## 主线独立验收

`test/ui-l84-acceptance.test.mjs` 两条：

1. 删除：打开 Modal 不发请求；取消不发请求；确认才发 `action=delete`。
2. 判定行：每天一组 `ul.dt-list`，两条记录两个 `li.dt-ticket`；日期标题不混作事件 `li`；时间使用 `time[dateTime]`。
