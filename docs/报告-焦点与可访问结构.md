## W11：SaveBar 与编辑关闭后的焦点归还

- `WatcherForm` 在提交前捕获表单、SaveBar 和行标题 opener，并用 focus capture/blur capture 记录焦点所有权。
- 新建/编辑放弃、新增保存后，回到当前表单首个仍存活且已解除 disabled 的可编辑控件；编辑保存关闭整个表单后回该行 `.dt-open`。
- 首个可编辑控件在 `setTimeout(0)` 内查询，避免 busy 尚未解除时得到 null；聚焦使用 `preventScroll`。
- 仅在保存成功或放弃后归还。失败保留草稿、编辑表单和 SaveBar alert，不执行 opener 回焦。
- timer 执行前再次检查当前焦点和所有权；用户已移到搜索等其他存活控件时不抢焦点，也不聚焦 detached 节点。

## W12：Disclosure busy 防重入

- `DisclosureRow` 接收 `busy`/`disabled`，busy 时输出 `tabIndex=-1`、`aria-disabled=true`、`aria-busy=true`。
- 可访问名称在 busy 时包含“保存中，暂不可开合”，不再出现可聚焦但操作被静默吞掉的状态。
- click 与 Enter/Space 在组件本层均有 guard；`event.repeat` 被忽略，长按不会反复开合。
- `WatcherForm` 两个场景均透传 busy/disabled，并以同步 `busyRef` 防止连点穿透首次 render 前的空隙。

## W13：Section heading

- 共享 `Section` 从 `div.dt-section-title` 改为官方同构的 `h2.dt-section-title`，形成页面 `h1 → h2` 层级。
- 总览、判定、触发和五个设置分区共用此实现，包括日期分组。
- 未增加 CSS：保留 class、margin、font-weight 和既有响应式字级。Chromium 实测总览/判定/触发为 14px/600，设置为 15px/600，margin 均为 0。

官方结构依据：`docs/official-gui-ia.md` 的 Section 条目与 `docs/ui-decomp/02-superagent-assets.md` 均为 `section.dt-section > h2.dt-section-title`。

## W14：持久异步错误与重复播报

- 追溯失败、全局持久 notice、首败/stale 读取错误和更新检查失败均补 `role=alert`、`aria-atomic=true`。
- 不把整页或整个 tabpanel 设为 live；历史 watcher 错误保持可见但不新增自动播报，避免旧错误播报风暴。
- `/state` 同文且非 loading 的失败复用前一个 snap，避免轮询重建或重写 alert；错误文本变化仍更新，成功/304 会移除错误。
- Chromium MutationObserver 实测：连续同文失败保持同一 alert DOM 节点，文本 mutation 为 0；新文本会更新，恢复会移除。
