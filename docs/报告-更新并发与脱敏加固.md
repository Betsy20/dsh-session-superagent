## 实现与回归对应

### 1. 超时与并发锁

- `lib/update.js` 在超时回调中先保存 `timeoutResult`，再发送 `SIGKILL`，不立即 `finish()`。
- `close` 到达后优先返回保存的 `timeoutResult`；即使真实退出码为数字或信号导致无退出码，超时语义仍保持为 `code: 'timeout'`。
- 超时后的 `error` 事件不提前结算，仍等待 `close`。
- `runExclusiveUpdate` 原有逻辑保持：外层 504 后，只有 runner 实际结算才释放全局更新锁。

回归 `spawn 超时后未 close 时 runner 保持 pending，外层 504 后第二个 POST 始终 409` 使用收到 `kill` 后不发 `close` 的假 child：首个请求 504 后连续两次请求均为 409，spawn 总数始终为 1；测试收尾补发 `close`，验证迟到结算后锁可释放。另一条回归验证正常 `kill → close` 仍返回 `timeout`。

### 2. 16 KiB 边界脱敏与 UTF-8

- `lib/update.js` 引入现有 `redact.js`。
- `normalizeRunnerResult` 的顺序改为：完整字符串脱敏 → UTF-8 安全截断 → 保留截断标记。
- `lib/index.js` 路由响应中的再次脱敏保持不变，形成纵深防御。

回归动态拼接假 GitHub token，并令其横跨 16 KiB 边界；后缀使用四字节 emoji，强制截断点落在多字节字符中间。断言响应不包含 token 的完整值或任何长度至少为 4 的前缀，输出不超过 16 KiB，不含 `U+FFFD`，UTF-8 编解码往返一致，且截断标记为 true。

### 3. Electron 直接执行 bin.js

- `.js` / `.mjs` / `.cjs` 命令解析结果由空 `env` 改为 `{ ELECTRON_RUN_AS_NODE: '1' }`。
- 形状测试同时覆盖 asar 内官方 `bin.js` 与显式 `DSH_CLI_PATH=cli.js`。
- spawn 形状测试验证 `PATH`、`DSH_PROFILE`、`DSH_PROFILE_DIR` 原样传入，且 `ELECTRON_RUN_AS_NODE=1` 能覆盖继承的错误值。
