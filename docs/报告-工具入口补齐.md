## 1. 实现位置与行为

### 1.1 `watch_stop(delete?: boolean)`

实现：`lib/index.js:3037-3078`；墓碑重建支持：`lib/index.js:248-258`、`lib/index.js:2922-2924`。

- 缺省 `delete=false`：仍然只暂停，保留 watcher；文本仍为 `stopped <id>`，JSON 仍只有 `schemaVersion / ok / id / repo`，没有新增 `deleted` 或 `stopped` 字段。
- `delete:true`：先调用既有 `stopWatcher(id)`（同时清理轮询 timer 与 `bootTimers`），再删除 `state.watchers[id]`，写入 `state.deleted[id] = new Date().toISOString()` 并 `writeState`。
- 删除回执：JSON 增加布尔值 `deleted:true`；文本明确包含 `deleted:true`。
- 沿用既有候选 id 查找，`gitee:owner/name` 与 `owner/name` 都能命中当前 session 的 Gitee watcher。
- `watch_start` 显式重建同一 repo/session 时，通过 `writeState(..., { revive:[id] })` 只解除该 id 的墓碑；普通迟到快照仍不能复活已删 watcher。

### 1.2 `watch_start(priority?: object)`

实现：`lib/index.js:74`、`lib/index.js:2819`、`lib/index.js:2849-2855`、`lib/index.js:2895-2904`。

- schema 类型为 `object`，说明中列出五个布尔键，`additionalProperties` 不限制。
- 默认值来自 `DEFAULT_PRIORITY`，并补扩展键 `stale:false`：

| 键 | 默认值 |
| --- | --- |
| `reopened` | `true` |
| `comments` | `true` |
| `labels` | `true` |
| `unassigned` | `false` |
| `stale` | `false` |

- 传入 `priority` 时，只覆盖显式给出且值为 boolean 的上述键；其余已有设置（包括扩展键）保留。
- 不传 `priority` 时不改写已有 watcher 的 `priority`；只改 `labels` 等过滤条件不会丢优先级配置。

### 1.3 `watch_doctor` 真实路由数

实现：`lib/index.js:2588-2610`。

- 部分失败时，以 `state.server.routes` 的实际成功数为分子，以 `routes + failed.length` 为分母；不再硬编码 `/6`，也没有改写死为 9。
- 无失败时直接报告 `state.server.routes`。
- 旧版本没有有效 `routes` 数据时显示「成功/总数未知」或「路由数未知」，不把缺失误报为 0，也不编造分母。

### 1.4 `/state` watcher 投影补 `ackLabel`

实现：`lib/index.js:1762`。

- 每条 watcher 返回 `ackLabel: w.ackLabel || defaultAckLabel(w.provider)`。
- 自定义标签原样返回；缺失时 GitHub 使用 `DEFAULT_ACK_LABEL`，Gitee 使用 `DEFAULT_ACK_LABEL_GITEE`。
- 未增加时间戳等不稳定字段。
