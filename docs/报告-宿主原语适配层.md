# L84d 宿主原语适配层报告

## 交付边界

本次只新增独立适配模块、对应假对象测试和本报告；没有修改 `client.js`、`package.json`、`lib/`、既有测试、派单表或 contract fixture，也没有 commit/publish。

适配层不接管业务确认、watcher 状态或 StatusOrbit，不实现自己的焦点圈、portal、定位、Toast timer 或第三套 Tooltip。

## exports 与调用面

`ui-host-primitives.js` 的 ESM 具名 exports：

- `createHostUi({ React, primitives })`
- `dismissToast(current, id)`：纯函数；仅 `current.id === id` 时返回 `null`，否则原样返回 `current`。

`createHostUi` 返回：

- `Modal({ open, title, description, footer, onClose, className, children })`
  - `open=false` 直接返回 `null`。
  - 打开时创建 `primitives.Modal`，透传上述参数并固定补 `closeLabel:'关闭'`。
  - 焦点、Escape、背板与 modal stack 全部留给宿主。
- `Toast({ item, onDone })`，其中 `item={ id, text, tone }`
  - 创建带 `key:item.id` 的 `primitives.Toast`，固定 `holdMs:3000`。
  - `onDone` 适配为只回传 `item.id`，不透传宿主事件或其他参数。
  - `success` 不传 `icon`，保留宿主内建勾；`error` 显式创建官方 `IconWarningOutlineMedium`。
  - 同时只保留最新一条仍由调用方负责；适配层没有队列或第二套 timer。
- `Tooltip({ text, icon, warn, children })`
  - 创建 `primitives.Tooltip`，映射 `label:text`，固定 `side:'top'`、`portal:true`、`openOnClick:true`、`gap:8`。
  - `children` 若提供，必须是单个 React element；字符串、数组和 `null` 都显式抛错。
  - 省略 `children` 时保留原 InfoTip 的 `button.dt-info`、`warn` 对应的 `dt-info-warn`；默认 question、可选 info/warning 图标均来自 primitives，也接受调用方传入的 React icon element，不自绘 SVG。
  - 缺少 `primitives.Tooltip` 时显式抛出“不可用”，不会回退到本地弹层。
- `createToastState()`
  - 返回 `{ item, notify, dismiss }`。`notify(text,tone)` 替换当前 item，`dismiss(id)` 用函数式 state 更新执行 `dismissToast`。
  - 调用方可把 `dismiss` 直接传给适配 Toast 的 `onDone`；计时只由宿主 Toast 负责。
- 同名 `dismissToast` 引用，便于集成时只从 factory 返回值取用。

## 真实 API 调用证据

依据 [04-host-primitives-smoke.md](ui-decomp/04-host-primitives-smoke.md)：

1. 该记录通过安装版 web bundle 的真实 `__ModuleLoader__.create({ staticModules })` 捕获 primitives，并经主理鱼 factory 注入的 `require('@deepseek-ai/dsh-client-ui-primitives')` 取得同一对象：`sameIdentity:true`、`exportCount:290`、React `18.3.1`（文档 `:30-43`）。因此适配器只接收宿主注入对象，不做普通 Node 包解析。
2. `Modal` 的真实参数包括 `open,onClose,title,closeLabel,description,children,footer,className`（文档 `:147-164`）。
3. `Toast` 的真实参数为 `{ text, icon, tone, anchor, holdMs=3000, actions, onDone }`；源码直接调用无参 `onDone()`，success 才自带勾，error 需显式 icon（文档 `:183-196`）。
4. `Tooltip` 的真实参数为 `{ label, side='right', gap=8, portal=false, openOnClick=false, children, ... }`；children 必须可由宿主 `cloneElement`，`openOnClick=true` 才启用 pinned click 模式（文档 `:198-216`）。
5. `IconWarningOutlineMedium`、`IconQuestionOutlineMedium`、`IconInfoOutlineMedium` 均在真实 290 exports 清单内（文档 `:88-140`）。
6. keyed Toast、按 id 清除、显式 error icon 与 `holdMs:3000` 的迁移约束见同文档 `:335-344`；Tooltip 参数建议见 `:315-320`。

本模块把这些真实参数连成可测试的薄调用面；没有把上述 smoke 改写为浏览器验收结论。

## 测试证据与未验项

定向实测命令与结果：

```text
node --test test/host-primitives-adapter.test.mjs
tests 8 / pass 8 / fail 0
```

全量 `npm test` 实测两轮，适配层 8 项在两轮中都全部通过：

1. 首轮 `tests 475 / pass 466 / fail 9`：`test/meta.test.mjs` 报告 `dt-priority`、`dt-watcher-form` 缺少 CSS，`test/ui-l84-form-acceptance.test.mjs` 8 项找不到 watcher 表单、高级 Disclosure 或 Field。
2. 并行表单任务继续修改后复跑 `tests 475 / pass 470 / fail 5`：3 项在 `test/client.test.mjs`（隔离回收文案、defaults 占位符、新建表单每小时上限字段），1 项仍是 `test/meta.test.mjs` 的上述 CSS 缺类，1 项是 `test/ui-l84-form-acceptance.test.mjs` 的新增/编辑同名字段 DOM 漂移。

这些失败均位于并行任务的 `client.js` 表单/CSS 及其验收测试；本任务可写边界不含这些文件，因此未为凑绿修改它们。全量绿灯需父代理在并行表单任务完成后统一复跑确认，本报告不把当前全量结果写成通过。

测试文件：`test/host-primitives-adapter.test.mjs`。使用假 React（包含与真 React 一致把 `key` 从 `props` 剥离的行为）和假 primitives，验证：

- Modal 的 props 透传、中文 `closeLabel` 与关闭不渲染；
- Toast 的真实元素 `key`、`holdMs`、success/error 图标分支、无参宿主完成回调到 `onDone(id)` 的转换；
- Tooltip 的 `label/side/portal/openOnClick/gap`、单 element 约束、默认 trigger 样式及缺少原语时显式报错；
- `dismissToast` 的 id guard 与 `createToastState` 的替换/函数式清除。

测试没有 mount 真实 React，没有执行宿主 effects、计时器或 DOM 事件，因此**不宣称浏览器行为已验证**。以下仍待宿主/真实浏览器验收：Modal 焦点圈与焦点归还、Escape/背板、轮询不抢焦点；Toast 的 3+1 秒生命周期、fade、连续通知重挂载与 `role=alert` 读屏；Tooltip 的 hover/focus/touch/click、Escape/Tab、外点、portal 叠放、边缘定位与 scroll-close。

特别是 Tooltip 适配器**尚未实现 scroll-close**，这是后续接入 `client.js` 前的独立集成项；不能仅凭本模块测试通过就删除现有 InfoTip。真实 DSH Toast 根语义为 `role=alert`，不是旧实现的 `role=status/aria-live=polite`。
