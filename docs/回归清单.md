# 回归清单：最容易退化的五项

> 由 `scripts/render-regression-doc.mjs` 生成，清单来自 `scripts/regression-list.mjs`。
> 每一项都配了"把它改坏，检查必须红"的反向用例（`node scripts/regression-cases.mjs`）。

| # | 会退化成什么 | 反向用例怎么造 | 对应的知识库 |
|---|---|---|---|
| 1 | README 写死的单测数/冷却期等与代码不一致 | README 数字漂移 | [`readme-numbers-come-from-code.md`](kb/readme-numbers-come-from-code.md) |
| 2 | 同一句中文在源码里出现两次（改一处忘另一处） | 整句文案重复 | [`recurring-theme-means-missing-check.md`](kb/recurring-theme-means-missing-check.md) |
| 3 | 运行必需的文件没进 npm 包（装上但不工作） | 打包缺必需文件 | [`pack-check-both-directions.md`](kb/pack-check-both-directions.md) |
| 4 | 改了「--fast 跳过什么」的清单但没重新生成文档 | 模式差异文档漂移 | [`cheap-mode-needs-a-contract.md`](kb/cheap-mode-needs-a-contract.md) |
| 5 | 面板顶部「主理中/已暂停/异常/时段外」加起来不等于总数 | 计数加不上总数 | [`counters-must-partition.md`](kb/counters-must-partition.md) |

## 怎么跑

```bash
node scripts/regression-cases.mjs   # 5/5 通过才算没退化
```

已接进 `preflight`（「反向用例」一项）：任何一项"改坏不会红"，门禁整体就红。
