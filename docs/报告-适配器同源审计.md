## 方法：提取结构，不做逐字比较

审计器不依赖第三方包。它先做词法屏蔽，再按括号边界提取函数、调用实参、对象属性、解构参数、`if` / `try...catch`、effect 和语句顺序，最后逐字段比较语义值。

它不是简单的名称 grep，也不要求两侧源码逐字相同：

- 允许注释、空白和单双引号风格差异；
- 归一化合法 UMD 别名：`h` / `hostH`、`React` / `HostReact`；
- 支持独立模块的函数声明与 UMD 的 `const HostX = … => { … }` 形态差异；
- 对固定契约同时检查双方一致和约定值，例如双方都为 `holdMs: 4500` 仍会失败；
- 单侧字段缺失时输出字段路径、独立值、UMD 值与 `<缺失>`；函数或实参结构无法提取时输出可读原因。
