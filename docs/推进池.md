# 推进池（每轮从这取一项，取完划掉）

> 用途：让"下一轮做什么"不再临时想。**池里的每一项都必须能离线验证** ——
> 需要真机宿主 / 网络 / npm registry 的事不进池（它们只进"攒批清单"）。

## 取用规则

1. 从上往下取第一条未完成的；
2. 单项 30 分钟内收口，做不到就拆小或放回；
3. 每轮结束：勾掉、写 CHANGELOG、更新 `docs/kb/` 至少一条；
4. **遇到需要宿主/网络/用户交互** → 立刻换下一条，不在原地等。
