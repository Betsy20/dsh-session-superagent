# 稳定版状态修复报告（N1/N2/N3）

## N1 保存成功却被顶掉成假失败

- `load()` 被更新请求顶掉时，不再直接返回 null，而是等待最新那次 load 的结果。
- 最新结果成功则保存成功；最新结果失败仍报错。
- POST200+GET500 的既有用例保持失败语义。

## N2 删除失败残留到下一次确认框

- 打开删除确认前清掉「删除失败：」错误，保留读取错误。
- 关闭确认框同样清删除错误。
- 本次删除失败仍由 `act()` 写入当前 Modal，并保留重试。

## N3 ETag 作用域串用

- `/state` 的 ETag 改为按完整 path（含 sessionId）分开存储。
- 圆环全局 `/state` 与会话面板 `/state?sessionId=…` 不再共用 etag。
- 两个会话互不复用；无 sessionId 的旧行为保留。
