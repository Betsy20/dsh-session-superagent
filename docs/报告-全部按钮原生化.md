# 全部按钮原生化报告

## 结论

在 primary 已接入 DSH `Button` 的基础上，`Btn` 现在对官方真实存在的 `primary / ghost / outline / toolbar` 全部统一委托，默认仍为官方一致的 `ghost / md`。业务使用的 `link` 在官方 `Button` 中不存在，因此保留原 `button.dt-btn-link`，没有映射成 `ghost`、`outline` 或 `toolbar`。

宿主缺少 `Button` 或整个 `@deepseek-ai/dsh-client-ui-primitives` 不可用时，所有 variant 都完整回退旧 DOM、旧 class 合并与旧 icon 包裹结构；回退所需样式没有删除。

本次只修改 `client.js`、`test/update-ui.test.mjs` 和本报告。`test/client.test.mjs` 无需修改；未改 `lib/`、package、版本、preflight、派单表，未 commit、未 push。

## 1. 官方能力核对

核对基线为安装版 DSH `0.2.1-rc.5`：既有反编译镜像 `D:/DeepSeek Harness/default-workspace/dsh-ui/tmp/official-primitives-bundle.js:129` 中，`Button` 的编译定义为 `variant="ghost"`、`size="md"`，样式映射包含 `primary / ghost / outline / toolbar` 与 `md / sm`。

同时对照官方固定 rev `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`：

- [Button.tsx](https://github.com/deepseek-ai/deepseek-harness/blob/66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db/packages/client/ui-primitives/src/Button.tsx)：`ButtonVariant = 'primary' | 'ghost' | 'outline' | 'toolbar'`；使用 `forwardRef`，原生 button attributes 透传。
- [Button.module.css](https://github.com/deepseek-ai/deepseek-harness/blob/66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db/packages/client/ui-primitives/src/Button.module.css)：`md` 高 36px，`sm` 高 28px；`ghost`、`outline` 均有独立官方规则，不是业务自造名称。

| 项目 | 官方事实 | 本次处理 |
|---|---|---|
| 默认 variant / size | `ghost / md` | `Btn` 保持相同默认值，并有直接断言 |
| 官方 variant | `primary / ghost / outline / toolbar` | 有宿主 `Button` 时全部委托 |
| 官方 size | `md / sm` | 原样转发 |
| 业务 `link` | 官方 variant 集合中不存在 | 保留旧 `dt-btn-link`，不自造映射 |
| icon | 官方 `icon` prop，内部自行包裹 | 宿主路径直接传 icon，不复制旧 span |
| ref / 原生 props | 官方支持 | `ref`、`type`、`onClick`、`disabled`、aria 等原样转发 |

## 2. 实现范围与回退边界

`client.js` 的共享 `Btn` 增加 `HOST_BUTTON_VARIANTS`，只有集合内的 variant 进入宿主分支：

1. **宿主路径**：调用 `h(hostButton, { type: 'button', ...rest, variant, size, icon, className }, children)`。显式 `type: 'submit'` 通过 `...rest` 覆盖默认值；`key` 仍由 React 管理，不写入 `props.key`。
2. **业务 className 保留**：`dt-danger`、`dt-btn-busy` 和其它业务类原样交给宿主；不重新拼接旧 `dt-btn`、`dt-btn-${variant}`、`dt-btn-${size}`，避免旧 CSS 覆盖宿主主题。
3. **完整旧回退**：缺 `Button` 或 primitives 时仍返回原生 `button`，保留 `dt-btn`、variant/size class、业务 class、`span.dt-btn-icon` 与 children 顺序。
4. **非官方 variant**：即使宿主 `Button` 存在，`link` 也走上述完整旧回退。
5. **样式保留**：`PORTED_CSS` 与 `DOCK_CSS` 未删改，旧宿主和 `link` 所需样式继续存在。

源码范围计数（文本声明计数，不等于页面最终按钮总数）：直接 `h(Btn, …)` **25 处**；显式 `variant` 声明为 primary **10**、ghost **12**、outline **3**、link **1**、toolbar **0**。未显式写 variant 的调用继续使用默认 ghost；共享 `ConfirmDialog` / `ConfirmButton` 另按其实际渲染场景验收。

本任务只统一 `Btn` 适配层，没有扩张改写 `SegTabs`、`Pill`、`Stat`、Orbit 触发器等独立原生 button。

## 3. 场景覆盖

定向测试执行真实 `client.js` UMD，并注入可辨识的宿主 `Button`，不是另写一份适配器复制品：

- 四种官方 variant 逐一验证委托，以及 `type/ref/key/icon/size/onClick/disabled/aria/className`；另验缺省 `ghost/md` 和 `link` 不映射。
- 缺 `Button`、缺整个 primitives 两种环境，逐一验证五种 variant（含 `link`）的旧 DOM 与完整 props。
- 既有 **8 个直接 primary 场景**保持委托：Onboarding、判定空态、空白/脏新增表单、保存凭证、保存 goal、读取失败重试、复制规则；SaveBar 的 ghost 放弃按钮也改为宿主委托。
- 普通 ghost/outline：行内立刻、暂停、删除、网络错误立刻重试、复制命令、重新检查、复制诊断信息；检查 icon、`aria-label`、`aria-haspopup`、disabled 和 onClick。
- 提交：新增表单空白时 `type=submit + disabled`，填写后仍可提交，显式 type 未被默认 button 覆盖。
- 危险确认与取消：确认按钮保留 `dt-danger`，busy 时保留 `dt-btn-busy + disabled + aria-busy`；ghost 取消按钮同样委托。
- 安装更新：既有 deferred POST、busy 防重入、busy 禁止 dismiss、成功/失败/结果未知及旧宿主 POST 回退测试全部继续通过。
- `link` 的「看建议规则」保持原生 button、旧 class、aria 与 onClick。
