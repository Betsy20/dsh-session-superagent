## 5. 本轮新发现

### 值得改

**N1（已复现）保存成功后回读被「刷新」或轮询顶掉，会假报「回读失败，请重试」。**

- 复现：goal 有改动 → 点「保存 goal」→ POST 未返回时点「刷新」→ 保存触发的 GET 与刷新的 GET 并发；
  刷新的 GET 先回（新序号），保存的 GET 后回（旧序号）被 `load()` 丢弃并返回 `null`，
  `run()` 的 `requireReload` 分支就抛错。凭证保存同一条路径。
- 实测输出（受控 fetch 探针，本 worktree 的 `client.js` + `test/fixtures/panel-harness.mjs`）：

  ```
  state idx7 [{"index":7,"next":{"text":"goal 已提交，但回读失败，请重试","tone":"error"}}]
  ```

- 定位：[client.js:2212](../client.js#L2212)（旧序号直接 `return null`）、
  [2326-2333](../client.js#L2326)（`null` 一律当失败）、[2529](../client.js#L2529)（goal）、
  [2506](../client.js#L2506)（凭证）。
- 影响：保存其实成功、数据也已刷新，用户看到红色失败提示并可能重复保存；真实概率 ≈ 回读耗时 / 5 s。
- 最小修复：`load()` 在「被更新的一次顶掉」时 `await` 最新那次的结果再返回，而不是 `null`；
  或 `run()` 区分「失败」与「被顶掉」（后者等最新快照）。验证：上述时序下不再出 error toast，
  且 POST200+GET500 仍然报错（已有用例 2043/2068 保持绿）。

**N2（静态确定）删除失败的错误会残留到下一次删除确认框。**

- 复现：Orbit 删除 A 失败（409/断网）→「取消」或 Escape 关掉确认框 → 点 B 的「删除」：
  新确认框一打开就带着上一次的「删除失败：…」，此时 B 还没发任何请求。
- 定位：`orbitError` 只在 [client.js:1811](../client.js#L1811)（开始删除时）和
  [1823](../client.js#L1823)（写成功）被清；`requestConfirm`（[client.js:178-193](../client.js#L178)）
  与 `closeConfirm`（[client.js:1834-1837](../client.js#L1834)）都不清；
  `deleteError` 直接取自它（[1839](../client.js#L1839)）并传给确认框（[1990-2002](../client.js#L1990)）。
- 影响：误导读成「B 也删失败」；错误文案不带仓库名，更分不清。
- 最小修复：`onRequestConfirm` 或确认框 `open` 时清掉「删除失败：」前缀的错误（保留读错误）。
  验证：失败→取消→重开任一删除，框内无旧错误；重试仍能在框内看到本次失败。

**N3（静态确定）模块级 `stateEtag` 被两个作用域共用，主面板的条件请求永远打不中 304。**

- 事实：`call()` 对任何 `/state` 响应都写同一个 `stateEtag`（[client.js:519](../client.js#L519)、
  [554-558](../client.js#L554)）；Orbit 每 5 s 无条件拉一次 `/state`（[1687-1714](../client.js#L1687)），
  写进去的是**全局作用域**的 etag；主面板随后用它去问 `/state?sessionId=…`（[2211](../client.js#L2211)）。
  服务端 etag 是对整份 body 求的（[lib/index.js:1979-1984](../lib/index.js#L1979)），两会话 body 不同 →
  etag 不同 → 必然 200。
- 影响：面板在打开期间每 5 s 收一次全量（preflight 实测 20 守 43.8 KB）并整页重渲染一次；
  0.9.285 之前两个调用方同作用域，304 是能命中的，所以这是 M1 修复带来的**性能回归**，不是串值。
- 最小修复：etag 按 scope 存（例如 `stateEtag[scope]`，scope = 路径 + sessionId）。
  验证：面板 200 → 再次轮询 304 且 `setSnap` 不产生新 body；两会话互不复用。
